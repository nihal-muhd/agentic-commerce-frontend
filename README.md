# Agentic Commerce Frontend

A production-style e-commerce frontend built with Next.js and TypeScript. The application includes customer shopping flows, admin product management, production media handling, and a real-time interface for monitoring AI-powered incident investigations.

## Features

### Customer

* User registration and login
* OAuth login
* Product listing
* Product details
* Shopping cart
* Checkout
* Responsive product images
* CDN-delivered media

### Admin

* Protected admin dashboard
* Product management
* Create, edit and delete products
* Product image upload
* Temporary upload handling
* Product image replacement and cleanup
* Incident dashboard
* Incident investigation view
* Human approval for agent actions
* Agent execution trace
* Real-time investigation updates using WebSockets

### Frontend Engineering

* Next.js App Router
* Server Components
* Client Components
* SSR
* ISR
* Static rendering
* Loading and error states
* BFF-based API communication
* WebSockets
* Dynamic imports
* Code splitting
* Bundle optimization
* Performance profiling
* Jest testing
* React Testing Library
* Playwright E2E testing
